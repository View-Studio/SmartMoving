## 6. SmartMovingMover.getPotionSpeedFactor (fix #44)

**파일**: SmartMovingMover.java L91-L110
**시그니처**: `public static float getPotionSpeedFactor(ClientPlayerEntity player)`

**식 (fix #44 — 1.7.10 MULTIPLY_TOTAL 식 직접 계산)**:
```java
public static float getPotionSpeedFactor(ClientPlayerEntity player) {
    if (!SmartMovingConfig.Config.enabled) return 1F;
    float base = 0.1F;
    float sprintMul = player.isSprinting() ? 1.3F : 1F;
    StatusEffectInstance speed = player.getStatusEffect(StatusEffects.SPEED);
    StatusEffectInstance slow  = player.getStatusEffect(StatusEffects.SLOWNESS);
    float speedMul = (speed != null) ? 1F + (speed.getAmplifier() + 1) * 0.2F : 1F;
    float slowMul  = (slow  != null) ? 1F + (slow.getAmplifier()  + 1) * (-0.15F) : 1F;
    float landMovementFactor = base * sprintMul * speedMul * slowMul;
    return landMovementFactor * 10F / sprintMul;
}
```

**의의**: vanilla 1.21.1 attribute 의 `ADD_MULTIPLIED_TOTAL` operation 우회. 1.7.10 의 `MULTIPLY_TOTAL` (각 modifier 별 누적 곱) 결과 직접 계산.

**예 (sprint + Speed LV3 = amplifier 2)**:
- `base=0.1, sprintMul=1.3, speedMul=1+(2+1)*0.2=1.6, slowMul=1`
- `landMovementFactor = 0.1 * 1.3 * 1.6 * 1 = 0.208`
- 반환 = `0.208 * 10 / 1.3 = 1.6`

## 9. f3 식 (slipperiness damping factor)

**SmartMovingMover.java L266**:
```java
float f3 = 0.1627714F / (horizontalDamping * horizontalDamping * horizontalDamping);
```

**상수**: `0.1627714F` (= vanilla 1.21.1 / 1.7.10 의 walkSpeed × slipperiness² 등가치 매직넘버).

**evaluations** (지상, slip=0.6 → horizontalDamping = 0.6 × 0.91 = 0.546):
- damping³ = 0.546³ = 0.16277...
- f3 = 0.1627714 / 0.16277 ≈ 1.0000...
- rawSpeed = 0.1 × 1.0 = 0.1

**evaluations** (얼음, slip=0.98 → horizontalDamping = 0.98 × 0.91 = 0.8918):
- damping³ = 0.8918³ ≈ 0.7094
- f3 ≈ 0.2294
- rawSpeed = 0.0229

## 23. 검증된 식 (sprint+W ground, slipperiness=0.6, SPEED LV3 시)

**입력**:
- `player.isOnGround() = true`
- `player.isSprinting() = true`
- `sm.isFast = true` (B-1c2 6-OR 매치)
- W 누름: `moveForward = 0.98` (vanilla normalize, 조이스틱 X 가정 1.0)
- SPEED LV3: `amplifier = 2`
- slip = 0.6 → `horizontalDamping = 0.6 × 0.91 = 0.546`

**계산 (Mover.handleLand)**:
1. `getConfigSpeedFactor` (Creative 외) = `cfg.speedFactor × 1F = 1F`
2. `getPotionSpeedFactor`:
   - `base=0.1, sprintMul=1.3, speedMul=1+(2+1)×0.2=1.6, slowMul=1`
   - `landMovementFactor = 0.1 × 1.3 × 1.6 × 1 = 0.208`
   - 반환 = `0.208 × 10 / 1.3 = 1.6`
3. `getNonSlowInputSpeedFactor` (isFast=true, !isClimbing) = `1.0 × 1.5 = 1.5`
4. `getSlowInputSpeedFactor` (입력 사용 안 함, !crawl, !sneak, !ceiling) = `1.0`
5. `speedFactor = 1F × 1.6 × 1.5 = 2.4`
   - `slowFactor = 1.0` → vanilla=false 경로 → `speedFactor *= 1.0 = 2.4`
6. **horizontalDamping = 0.546** (지상)
7. **f3 = 0.1627714 / 0.546³ = 0.1627714 / 0.16277... ≈ 1.00000...**
8. **rawSpeed = 0.1 × f3 ≈ 0.1**
9. `cfg.run && isRunning && !isFast`: isFast=true → 분기 skip
10. !onGround=false → potionFactor 정상화 skip
11. `rawSpeed × speedFactor = 0.1 × 2.4 = 0.24`

**applyLandMoveFlying (W만, moveForward=0.98, moveStrafing=0)**:
1. f3 raw = `0² + 0.98² = 0.9604`
2. f3 = sqrt(0.9604) = 0.98 → `< 1.0` 이므로 1.0 으로 clamp
3. f3 = `0.24 / 1.0 = 0.24`
4. moveStrafing = `0 × 0.24 = 0`, moveForward = `0.98 × 0.24 = 0.2352`
5. yaw=0 (북향 가정): sin=0, cos=1
6. velX += `0×1 - 0.2352×0 = 0`
7. velZ += `0.2352×1 + 0×0 = 0.2352`

**ADD = (0, 0.2352)** (vy 무관)

**setLandMotions**:
- newX = `velX × 0.546`
- newZ = `velZ × 0.546`
- newY = `(vy - 0.08) × 0.98`

**Terminal speed (steady-state, ADD = damping × terminal × (1-damping)/(1-damping) = ADD/(1-damping))**:
- 매 tick 식: `vNext = (v + ADD) × damping`
- steady: `v = (v + ADD) × damping → v(1-damping) = ADD × damping → v = ADD × damping / (1-damping)`
- = `0.2352 × 0.546 / (1 - 0.546)`
- = `0.12842 / 0.454`
- = **0.2828 (terminal motion m/tick)**
- = **5.657 m/s** (× 20 tick/s)

**검증**: 이전 사용자 보고 "SM 활성 ground sprint+speed1 W 누름 = motion ADD 0.1764, terminal 0.388" 와 비교.
- speed1 (amplifier=0): `speedMul = 1.2`, `landMovementFactor = 0.1×1.3×1.2 = 0.156`, `getPotionSpeedFactor = 0.156×10/1.3 = 1.2`
- `speedFactor = 1×1.2×1.5 = 1.8`, `rawSpeed×speedFactor = 0.18`
- `applyLandMoveFlying ADD = 0.18 × 0.98 (moveForward 정규화) ≈ 0.1764`
- `terminal = 0.1764 × 0.546 / 0.454 ≈ 0.2122`
- ⚠️ 사용자 보고 0.388 과 차이 — 추가 sprint modifier 또는 GENERIC_MOVEMENT_SPEED attribute 가 다른 곳에서 적용될 가능성. SPRINT-SPEED-DBG 가 `getMS=<player.getMovementSpeed()>` 로 vanilla attribute 값을 같이 출력 중.
