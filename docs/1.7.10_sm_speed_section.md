```java
    double diffY = sp.posY - d1_S;
```

- SPEED LV3 → AIMoveSpeed=0.1×1.6=0.16 → potionFactor=1.6 (sprint 시 1.6/1.3=1.2308)

```java
private float getSlowInputSpeedFactor(float moveForward, float moveStrafing)
{
    float speedFactor = 1f;

    if (sp.isUsingItem())
    {
        float itemFactor = 0.2F;                           // 기본 0.2F
        if(Config.enabled)
        {
            Item item = sp.getItemInUse().getItem();
            if(item instanceof ItemSword)
                itemFactor = Config._usageSwordSpeedFactor.value;
            else if(item instanceof ItemBow)
                itemFactor = Config._usageBowSpeedFactor.value;
            else if(item instanceof ItemFood)
                itemFactor = Config._usageFoodSpeedFactor.value;
            else
                itemFactor = Config._usageSpeedFactor.value;   // 기본 0.2F
        }
        speedFactor *= itemFactor;
    }

    if(isCrawling || (isCrawlClimbing && !isClimbCrawling))
        speedFactor *= Config._crawlFactor.value;          // 기본 0.15F
    else if(isSlow)
        speedFactor *= Config._sneakFactor.value;          // 기본 0.3F

    if(isCeilingClimbing)
        speedFactor *= Config._ceilingClimbingSpeedFactor.value;  // 기본 0.2F

    return speedFactor;
}
```

```java
private float getNonSlowInputSpeedFactor(float moveForward, float moveStrafing)
{
    float speedFactor = 1f;

    if(isFast)
        speedFactor *= (!isLevitating() ? Config._sprintFactor.value : Config._sprintFactorLevitate.value);
        // 기본: _sprintFactor=1.5F, _sprintFactorLevitate=1.5F (creative 시 3F)
    if(isClimbing)
        if(moveStrafing != 0F || moveForward != 0F)
            speedFactor *= Config._freeClimbingHorizontalSpeedFactor.value;
        else if(wantClimbDown && isNeighborClimbing && !(Math.abs(sp.posX - lastHorizontalCollisionX) < 0.05 && Math.abs(sp.posZ - lastHorizontalCollisionZ) < 0.05))
        {
            moveForward = ClimbPullMotion;   // 0.3F
            if(isVineOnlyClimbing)
            {
                if(handsEdgeMeta != Orientation.VineFrontMeta && feetEdgeMeta != Orientation.VineFrontMeta)
                    moveForward = 0F;
                else
                {
                    Orientation orientation = Orientation.getOrientation(sp, 45F, true, false);
                    if(orientation != null)
                    {
                        float gap = (float)orientation.getHorizontalBorderGap(sp);
                        float minGap = sp.width / 2;
                        float factor = Math.max(0, gap * (1 + minGap) - minGap);
                        moveForward = factor * factor * 0.3F;
                    }
                }
            }
        }
    return speedFactor;
}
```

### 5.1 진입 부 + horizontalDamping 결정 (이번 tick 용 — moveFlying 분모)
```java
private float landMotion(float moveForward, float moveStrafing, float speedFactor, boolean isOnLadder, boolean isOnVine)
{
    float horizontalDamping;
    if(sp.onGround && (!isJumping || vanilla()))
    {
        Block block = sp.worldObj.getBlock(MathHelper.floor_double(sp.posX), MathHelper.floor_double(sp.boundingBox.minY) - 1, MathHelper.floor_double(sp.posZ));
        if(block != null)
            horizontalDamping = block.slipperiness * HorizontalAirDamping;
            // slipperiness = 0.6F (대부분 블록), HorizontalAirDamping = 0.91F
            // → 0.6 × 0.91 = 0.546F
        else
            horizontalDamping = HorizontalGroundDamping;   // 0.546F (fallback)

        if(esp.movementInput.jump && isFast && Config.isJumpingEnabled(Config.Sprinting, Config.Up))
            speedFactor *= Config._sprintJumpVerticalFactor.value;
    }
    else
        horizontalDamping = HorizontalAirDamping;          // 0.91F (공중)
```

#### 매직 넘버 분석:
- `0.1627714F` = SmartMoving 의 **ground rawSpeed numerator**
- 0.1627714 ≈ 0.16277 ≈ 1/6.144 (vanilla 가속 효율 정규화)
- `f3 = 0.1627714F / damp³` (예: damp=0.546F → f3 = 0.1627714 / 0.16277 ≈ 1.000003)
- `rawSpeed` = onGround 시 `0.1F × f3` → ≈ 0.1F (0.10000003)
- 공중: `jumpMovementFactor / (sprint ? 1.3F : 1F)` (vanilla `jumpMovementFactor` 기본 0.02F)

#### sprint+W 평지 SPEED LV3 시 최종 motion 계산 (이정표):
- `speedFactor` = configSpeedFactor(1.0) × potionSpeedFactor × nonSlow(sprint=1.5F) × slow(아이템 사용 X)
- potionSpeedFactor (SPEED LV3) = 1.6 / 1.3 = 1.2308 (sprint 시)
- speedFactor = 1.0 × 1.2308 × 1.5 = 1.8462
- rawSpeed = 0.1F × 1.0 = 0.1F
- moveFlying 인자 = 0.1F × 1.8462 = 0.18462F
- vanilla `moveFlying`: motionX,Z += sin/cos × 0.18462F
- 다음 tick damping: motionX *= 0.546 (ground)

## 8. SmartMovingBase.moveFlying — 5-인자 override (3D 정규화)

**위치**: `SmartMovingBase.java:56-93`

```java
protected void moveFlying(float moveUpward, float moveStrafing, float moveForward, float speedFactor, boolean treeDimensional)
{
    float diffMotionXStrafing = 0, diffMotionXForward = 0, diffMotionZStrafing = 0, diffMotionZForward = 0;
    {
        float total = MathHelper.sqrt_float(moveStrafing * moveStrafing + moveForward * moveForward);
        if(total >= 0.01F)
        {
            if(total < 1.0F)
                total = 1.0F;

            float moveStrafingFactor = moveStrafing / total;
            float moveForwardFactor = moveForward / total;
            float sin = MathHelper.sin((sp.rotationYaw * 3.141593F) / 180F);
            float cos = MathHelper.cos((sp.rotationYaw * 3.141593F) / 180F);
            diffMotionXStrafing = moveStrafingFactor * cos;
            diffMotionXForward = -moveForwardFactor * sin;
            diffMotionZStrafing = moveStrafingFactor * sin;
            diffMotionZForward = moveForwardFactor * cos;
        }
    }

    float rotation = treeDimensional ? sp.rotationPitch / RadiantToAngle : 0;
    float divingHorizontalFactor = MathHelper.cos(rotation);
    float divingVerticalFactor = -MathHelper.sin(rotation) * Math.signum(moveForward);

    float diffMotionX = diffMotionXForward * divingHorizontalFactor + diffMotionXStrafing;
    float diffMotionY = MathHelper.sqrt_float(diffMotionXForward * diffMotionXForward + diffMotionZForward * diffMotionZForward) * divingVerticalFactor + moveUpward;
    float diffMotionZ = diffMotionZForward * divingHorizontalFactor + diffMotionZStrafing;

    float total = MathHelper.sqrt_float(MathHelper.sqrt_float(diffMotionX * diffMotionX + diffMotionZ * diffMotionZ) + diffMotionY * diffMotionY);
    if(total > 0.01F)
    {
        float factor = speedFactor / total;
        sp.motionX += diffMotionX * factor;
        sp.motionY += diffMotionY * factor;
        sp.motionZ += diffMotionZ * factor;
    }
}
```

## 17. 검증된 식 (sprint+W ground, slipperiness=0.6F, SPEED LV3, _sprintFactor=1.5F)

평형 상태 (terminal velocity) 시 motion 이 매 tick 동일:
- `motion_next = (motion_curr + accel) × damping = motion_curr`
- → `accel = motion_curr × (1 - damping) / damping`
- → `motion_curr = accel × damping / (1 - damping)`

매 tick:
- `accel_X = sin(yaw) × moveForward × rawSpeed × speedFactor`
- 평지 forward only: forward=1, strafe=0, sin(yaw)≈cos(yaw) 한 축 가정
- `damp = 0.546F`
- `rawSpeed = 0.1F × (0.1627714 / 0.546³) = 0.1F × (0.1627714 / 0.1627710) ≈ 0.1F × 1.0000023 ≈ 0.1F`
- `speedFactor (SPEED LV3) = configSF × potionSF × nonSlowSF × slowSF`
  - configSF = 1.0 × 1.0 = 1.0
  - potionSF (sprint, LV3) = (0.1 × 1.6) × 10 / 1.3 = 1.2308
  - nonSlowSF (isFast=true) = 1.5F (`_sprintFactor.value`)
  - slowSF (no item) = 1.0
  - `speedFactor = 1.0 × 1.2308 × 1.5 × 1.0 = 1.8462`
- `accel_per_axis = 1 × 0.1F × 1.8462 = 0.18462F`
- terminal motion (등속): `motion = 0.18462 × 0.546 / (1 - 0.546) = 0.18462 × 1.2026 = 0.222`

→ **평지 sprint+W SPEED LV3 ≈ 0.222 m/tick = 4.44 m/s** (vanilla 와 일치)

SPEED LV0 (포션 없음):
- potionSF = (0.1 × 1.0) × 10 / 1.3 = 0.7692
- speedFactor = 1.0 × 0.7692 × 1.5 = 1.1538
- accel = 0.1 × 1.1538 = 0.11538
- terminal motion = 0.11538 × 1.2026 = 0.13877 m/tick = 2.775 m/s

→ vanilla sprint+W 평지 = 5.612 m/s (sprint 1.3 ×) 와 다름. 하지만 SmartMoving 의 `_sprintFactor=1.5` 가 vanilla `1.3` 을 대체하므로 실제 약 5.5 m/s.

(참고 메모리: `reference_vanilla_movement_magic.md` — `0.21600002F/slip³ ≡ 0.16277/(slip × 0.91)³`)

옵션 정의 시 `.defaults(value)` 명시 안 하면 PositiveFactor 의 기본은 1F, DecreasingFactor 도 1F 가능. 옵션 chain 형태로 정의되므로 explicit `.defaults(...)` 만 본 표에 기록됨.

## 19. SmartMovingSelf의 isFast/isHeadJumping/isAerodynamic/isSliding 상호작용 정리 (속도에 직결)

| state | landMotion 영향 |
|---|---|
| `isHeadJumping = true` | `speedFactor *= 0.2F` (`_headJumpControlFactor`) |
| 공중 (sp.onGround=false, !sp.capabilities.isFlying, !isFlying) | `speedFactor *= 1F` (`_jumpControlFactor`) |
| `isSliding = true` | landMotion L701 `else if(!isSliding)` 으로 sp.moveFlying skip. 모든 horizontal accel 0 |
| `isAerodynamic = true && !sp.onGround` | `horizontalDamping = 0.999F` (다음 tick) → 거의 등속 활공 |
| `isFast = true && sp.onGround` | `nonSlowInputSpeedFactor *= 1.5F` |
| `isSlow = true (sneaking)` | `slowInputSpeedFactor *= 0.3F` |
| `isCrawling = true` | `slowInputSpeedFactor *= 0.15F` |
| 공중 (!sp.onGround) | `speedFactor /= getPotionSpeedFactor()` (= 공중에서는 SPEED 포션 효과 직접 적용 안 함, vanilla `jumpMovementFactor` 가 자체 적용) |

## 20. 매핑 시 주의사항 (1.21.1 포팅 적용)

1. **rawSpeed 식 그대로**: `0.1627714F / (slip × 0.91F)³` 이 vanilla 1.21.1 의 `0.21600002F / slip³` 과 등가 (메모리 `reference_vanilla_movement_magic.md` 확인)
2. **getPotionSpeedFactor 식**: `getLandMovementFactor() × 10F / (sp.isSprinting() ? 1.3F : 1F)` 그대로. `sp.getAIMoveSpeed()` 가 vanilla 1.21.1 에서도 SPEED 포션 결과 반영 (PlayerEntity.getMovementSpeed() 또는 getAttributeValue(MOVEMENT_SPEED))
3. **공중 rawSpeed**: vanilla 1.21.1 에 `jumpMovementFactor` field 없음. 결과식 `0.02F` hardcode 필수 (메모리 `feedback_air_sprint_rawspeed.md` 확인)
4. **moveFlying 인자 차이**: vanilla 3-인자 vs SmartMovingBase 5-인자 식 다름 (메모리 `feedback_moveFlying_landBranch_overload.md`)
5. **isAerodynamic**: 헤드점프 → fox movement 자동 전환 시 `horizontalDamping=0.999F` 매 tick. 누락 시 motion 1.2s 안에 0 (메모리 `feedback_aerodynamic_damping.md`)
6. **slipperiness**: vanilla 1.21.1 의 ice=0.98F, slime=0.8F 등 그대로
7. **PlayerAPI hook 위치**: 1.21.1 Fabric mixin 으로 변환. `EntityPlayerSP.onUpdate` → `LocalPlayer.tick`, `EntityLivingBase.moveEntityWithHeading` → `LivingEntity.travel(input)` (1.20+ 변경). `updateEntityActionState` → `LocalPlayer.aiStep` (vanilla 패턴)

## 21. 빠진 부분 (= 본 분석에서 "직접 영향 없음" 으로 판단해 의도적 제외)

- `handleSwimming` 의 모든 `motionYDiff` 분기 (수영/다이빙 — 평지 sprint 분석 제외)
- `handleLava` 전체 (라바 — 평지 sprint 분석 제외)
- `handleCeilingClimbing` 전체 (천장 등반 — `_ceilingClimbingSpeedFactor` 외 분석 안 함)
- `handleClimbing` 의 사다리/덩굴 grip 분기 (climbing — 평지 sprint 분석 제외)
- `handleWallJumping` (wall jump — 단발 jump motion 부여, sprint 누적 X)
- `handleExhaustion` 의 hunger 부분 (속도 영향 X, exhaustion threshold 만 영향)
- `correctOnUpdate` 의 회전 보정 (회전 — 속도 X)
- `tickEssential` / `updateEntityActionState` 의 키 입력 처리 (input → state 변환만)

이 항목들은 평지 sprint+W 의 motion 식에 직접 영향을 주지 않음.

## 22. 결론 (1줄 요약)

**평지 sprint+W 의 SmartMoving rawSpeed = `0.1F × (0.1627714F / (block.slipperiness × 0.91F)³) = 약 0.1F`. speedFactor = `_speedFactor × getUserSpeedFactor() × (AIMoveSpeed × 10 / 1.3) × _sprintFactor × slowInput`. 최종 moveFlying 인자 = rawSpeed × speedFactor. setLandMotions damping = `block.slipperiness × 0.91F = 0.546F` (ground), `0.91F` (air), `0.999F` (aerodynamic).**
