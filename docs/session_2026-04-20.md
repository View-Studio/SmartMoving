### 2. 애니메이션 전면 수정 — 계층 모델 좌표계 변환 버그

**수정된 파일:** `src/client/java/choco/ratel/smartmoving/mixin/client/PlayerEntityModelMixin.java`

#### 핵심 원인 분석

원본 SmartMoving(1.7.10)과 1.21.1의 모델 구조 차이:

| 구분 | 1.7.10 원본 | 1.21.1 현재 |
|------|------------|------------|
| 모델 구조 | **계층적** — `bipedOuter → bipedTorso → 팔/다리` | **flat** — 모든 파트가 독립적 |
| 각도 의미 | 팔/다리 각도 = **LOCAL** (부모 상대) | 팔/다리 각도 = **WORLD** (절대) |
| 변환 필요 | - | `world = parentPitch(outerX) + local` |

원본에서 `bipedOuter.rotateAngleX = outerX`로 설정했을 때, 팔/다리의 **world 각도** = `outerX + 팔/다리 LOCAL 각도`. 1.21.1 flat 모델에서 `outerX`에 해당하는 오프셋을 각 파트에 직접 더해야 한다.

#### 1차 수정 — LOCAL→WORLD 변환 (이전 세션)

각 애니메이션에서 `bodyPitch(outerX)`를 팔/다리 pitch에 더해 world 공간으로 변환:

```
applyCrawlingAngles   : bodyPitch = QUARTER - THIRTYTWOTH
applySlidingAngles    : bodyPitch = QUARTER
applySwimmingAngles   : outerX = QUARTER - SIXTEENTH*combined
applyDivingAngles     : outerX = QUARTER - vAngle
applyHeadJumpingAngles: outerX = QUARTER - vAngle
```

또한 수영 팔 pitch의 `SIXTEENTH*combined` 상쇄 항을 발견:
```
world arm pitch = outerX + local
= (QUARTER - SIXTEENTH*combined) + cycling + SIXTEENTH*combined
= QUARTER + cycling  ← 단순화됨
```

#### 2차 수정 — head.pitch, arm.yaw 추가 버그 수정 (오늘)

1차 수정 후에도 남아 있던 좌표계 오류 3가지:

**버그 1: 기어가기/슬라이딩 head.pitch**
```java
// 잘못된 코드 (LOCAL 값을 그대로 사용)
m.head.pitch = -bodyPitch;  // flat 모델에서 머리가 뒤로 78~90° 꺾임

// 수정된 코드
m.head.pitch = 0F;  // flat 모델에서 world pitch=0 = 앞 방향
```
원본에서 `head`는 `bipedTorso`의 자식이었으므로 `head.localPitch = -bodyPitch`이면
`head.worldPitch = bodyPitch + (-bodyPitch) = 0`. flat 모델에서는 그냥 `0F`.

**버그 2: 천장 클라이밍 arm.yaw**
```java
// 잘못된 코드 (LOCAL 값을 그대로 사용)
m.leftArm.yaw  = -rotateY;  // 팔이 엉뚱한 방향으로 회전
m.rightArm.yaw = -rotateY;

// 수정된 코드
m.leftArm.yaw  = 0F;  // flat 모델에서 팔은 body의 자식이 아님
m.rightArm.yaw = 0F;
```
원본에서 `-rotateY`는 `bipedOuter.rotateAngleY = rotateY` 부모 yaw를 상쇄하기 위한 LOCAL 값.
flat 모델에서 팔은 body의 자식이 아니므로 상쇄할 부모 yaw가 없다. `0F`이면 world yaw = 0.

**버그 3: 헤드점프 head.pitch**
```java
// 잘못된 코드
m.head.pitch = -outerX / 2F;  // 원본 LOCAL 값 그대로

// 수정된 코드
m.head.pitch = outerX / 2F;   // world pitch = outerX + (-outerX/2) = outerX/2
```
원본 world head pitch = `bipedOuter.pitch + head.localPitch = outerX + (-outerX/2) = outerX/2`.
flat 모델에서는 `outerX/2`를 직접 대입.
