BlockPos blockPos = this.getVelocityAffectingPos();
float p   = this.getWorld().getBlockState(blockPos).getBlock().getSlipperiness();   // 0.91f literal at L1042/1049

   q += (0.05 * (amp + 1) - vec3d6.y) * 0.2;

   q -= d;            // d = getFinalGravity()

                    this instanceof Flutterer ? q * fxx : q * 0.98F,    // 0.9800000190734863d (L1227)

## 2. LivingEntity.applyMovementInput(Vec3d, float slipperiness)

**시그니처**: `public Vec3d applyMovementInput(net.minecraft.util.math.Vec3d, float)`
**위치**: `livingdis.txt` L8360~8423, sources L2244~2255

```java
public Vec3d applyMovementInput(Vec3d movementInput, float slipperiness) {
   this.updateVelocity(this.getMovementSpeed(slipperiness), movementInput);
   this.setVelocity(this.applyClimbingSpeed(this.getVelocity()));
   this.move(MovementType.SELF, this.getVelocity());
   Vec3d vec3d = this.getVelocity();
   if ((this.horizontalCollision || this.jumping)
       && (this.isClimbing()
           || this.getBlockStateAtPos().isOf(Blocks.POWDER_SNOW)
              && PowderSnowBlock.canWalkOnPowderSnow(this))) {
      vec3d = new Vec3d(vec3d.x, 0.2, vec3d.z);    // 0.2d (#3035)
   }
   return vec3d;
}
```

**위치**: `livingdis.txt` L8563~8589, sources L2289~2291

   return this.isOnGround()

즉 vanilla default p=0.6 ground: getMovementSpeed(p) ≈ movementSpeed × 1.0.

## 6. Entity.updateVelocity(float, Vec3d) + movementInputToVelocity

**위치**: `entitydis.txt` L5365~5463

```java
public void updateVelocity(float speed, Vec3d movementInput) {
   Vec3d vec3d = movementInputToVelocity(movementInput, speed, this.getYaw());
   this.setVelocity(this.getVelocity().add(vec3d));
}

private static Vec3d movementInputToVelocity(Vec3d movementInput, float speed, float yaw) {
   double d = movementInput.lengthSquared();
   if (d < 1.0E-7d)  return Vec3d.ZERO;
   Vec3d vec3d = (d > 1.0d ? movementInput.normalize() : movementInput).multiply(speed);
   float f6 = MathHelper.sin(yaw * 0.017453292F);   // 0.017453292F = π/180
   float f7 = MathHelper.cos(yaw * 0.017453292F);
   return new Vec3d(vec3d.x * f7 - vec3d.z * f6,
                    vec3d.y,
                    vec3d.z * f7 + vec3d.x * f6);
}
```

**disasm (entitydis.txt L5391~5460)**:
```

5398: ldc2_w  #1051   double 1.0E-7d
5402: dload_3 dconst_1 dcmpl
5406: ifle    30                                ← d > 1.0 면 normalize
5408: invokevirtual normalize

```

**핵심 매직**:
| 값 | 의미 |
|---|---|
| `1.0E-7d` (#1051) | input 무시 임계값 |
| `1.0d` | normalize 임계값 (대각선 방지) |
| `0.017453292F` (#2034) | π/180 = degrees → radians |

이 식이 1.7.10 의 `moveFlying(strafe, forward, factor)` 와 동일 (strafe×cos - forward×sin, forward×cos + strafe×sin) 인데, **1.21.1 input.x = strafe(±1), input.z = forward(±1)** 이며 normalize 가 length²>1 시에만 적용 (대각선만, 1.0F+1.0F = 1.414 → normalize). 1.7.10 의 sqrt(sqrt(...)) 식과 다름.

실제: 평지 sprint+W 단방향 시 length²=1.0 ≤ 1.0 → normalize **안 함**, vec3d = (0, 0, 1)×speed.

## 18. KeyboardInput.tick (kbdis.txt 전체)

```java
public void tick(boolean slowDown, float slowDownFactor) {
   this.pressingForward = settings.forwardKey.isPressed();
   this.pressingBack    = settings.backKey.isPressed();
   this.pressingLeft    = settings.leftKey.isPressed();
   this.pressingRight   = settings.rightKey.isPressed();
   this.movementForward  = getMovementMultiplier(this.pressingForward, this.pressingBack);
   this.movementSideways = getMovementMultiplier(this.pressingLeft,    this.pressingRight);
   this.jumping  = settings.jumpKey.isPressed();
   this.sneaking = settings.sneakKey.isPressed();
   if (slowDown) {
      this.movementSideways *= slowDownFactor;
      this.movementForward  *= slowDownFactor;
   }
}

private static float getMovementMultiplier(boolean pos, boolean neg) {
   if (pos == neg) return 0.0F;       // 둘 다 / 둘 다 아님
   return pos ? 1.0F : -1.0F;
}
```

**중요**: `movementForward`, `movementSideways` 는 ±1.0F 또는 0F. **대각선 시 (1.0,1.0) 으로 들어가서 movementInputToVelocity 안에서 normalize 됨**.

## 20. 검증된 식 (1.21.1 평지 sprint+W 의 terminal speed)

**조건**: 평지 (slipperiness p=0.6), 효과 없음 (SPEED 0, SLOWNESS 0), 평범한 gear, isOnGround=true, sprint=true.

**Step 1 — 매 tick velocity 추가 (LivingEntity.applyMovementInput → updateVelocity)**:
```
movementSpeedAttr = 0.10000000149011612 × (1 + 0.30000001192092896)   // sprint
                  = 0.13000001346...

groundSpeed       = movementSpeedAttr × 0.21600002F / 0.6³
                  = 0.13000001346 × 0.21600002 / 0.216
                  = 0.13000001346 × 1.0000000926
                  = 0.13000002551...

input length²     = 1.0F² = 1.0     → normalize 안 함
input scaled      = (0, 0, 1) × groundSpeed = 0.13000003 forward

velocity_post_add += 0.13000003                                       (forward delta)
```

**Step 2 — Entity.move 안의 getVelocityMultiplier 적용 (default block velocityMultiplier=1.0)**:
```
velocity *= 1.0   (default block 영향 없음, efficiency=0 이므로 lerp(0, 1.0, 1.0) = 1.0)
```

**Step 3 — 평지 분기 마지막 setVelocity (livingdis.txt L1199~1240)**:
```
fxx = isOnGround ? 0.6 × 0.91 : 0.91   = 0.546
velocity.x *= 0.546
velocity.z *= 0.546
velocity.y *= 0.98 (Flutterer 아니므로)
```

**Terminal velocity 도출 (steady state, v_{n+1} = (v_n + delta) × fxx)**:
```
v* = (v* + 0.13000003) × 0.546
v* = 0.13000003 × 0.546 / (1 - 0.546)
v* = 0.07098 / 0.454
v* ≈ 0.156342 m/tick
```

**검증**: 위키 공식값 sprint terminal speed ≈ 0.155966 m/tick (0.10000000149011612 × 1.3 / (1/0.546 - 1) = 0.156342). 일치.

**Without sprint (W 평지)**:
```
movementSpeedAttr = 0.10000000149011612
groundSpeed       = 0.10000003 × 0.21600002 / 0.216 = 0.10000003
v* = 0.10000003 × 0.546 / 0.454 = 0.12026 m/tick
```

**SPEED LV1 + sprint**:
```
movementSpeedAttr = 0.10000000149011612 × 1.20000000298 × 1.30000001192
                  = 0.156000019...
groundSpeed       = 0.156 × 1.0000000926 = 0.156
v* = 0.156 × 0.546 / 0.454 = 0.18761 m/tick
```

## 21. 주의 사항 / 1.7.10 차이점

1. **SPRINTING boost 가 attribute 가 아님**: 1.21.1 yarn 에서는 `SPRINTING_SPEED_BOOST` 가 LivingEntity 의 `static EntityAttributeModifier` 이며, `setSprinting(true)` 호출 시 GENERIC_MOVEMENT_SPEED instance 에 `addTemporaryModifier` 로 추가되었다가 false 시 `removeModifier` 로 제거된다.

2. **getMovementSpeed(slipperiness) 의 0.21600002F**: `0.6³ = 0.216` 정규화 상수. p=0.6 (default block) 시 1.0 곱 → movementSpeed 그대로. p=0.98 (얼음) 시 약 0.2295 → 입력 가속도 1/4 수준이지만 fxx=0.98×0.91=0.8918 (vs 0.546) 로 마찰이 4배 약해 terminal 속도는 더 빠름.

3. **air sprint 식**: 1.7.10 의 `_jumpMovementFactor / 1.3F` (= 0.02/1.3 ≈ 0.01538) × 1.3 (sprint) = 0.02 식이 1.21.1 에서는 직접 `0.025999999F` (= 0.02 × 1.3) hardcode 됨. → vanilla 같음.

4. **input 정규화**: 1.7.10 의 sqrt(sqrt(strafe²+forward²)) 식 → 1.21.1 은 length² > 1.0 시 normalize, 아니면 그대로. **단방향 입력** 시 length²=1.0 정확히 ≤ 1.0 → normalize 안 함 (실제 효과 동일). **대각선 W+A** 시 length²=2.0 > 1.0 → normalize → magnitude 1.0 (= 정확히 1.0F speed).

5. **getVelocityMultiplier 의 lerp**: LivingEntity 가 `lerp(MOVEMENT_EFFICIENCY, super, 1.0F)` 로 wrap. 즉 efficiency 가 클수록 block 속도 차감을 무시한다. default=0 이므로 super(=block velocityMultiplier) 그대로.

6. **PlayerEntity.getMovementSpeed 가 attribute 직접 반환**: LivingEntity.movementSpeed 필드는 mob/animal 에서만 의미, player 는 attribute → 즉 mob travel ↔ player travel 의 base 값 정의 위치가 다름.

7. **getOffGroundSpeed 에 movementSpeed 가 곱해짐**: passenger 가 player 인 mob 의 air speed = movementSpeed × 0.1F (riding). 일반 player 는 0.025999999F or 0.02F.
